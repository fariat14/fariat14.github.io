# Faria T — Portfolio

Personal portfolio for my work in data analytics, finance transformation, applied research, and writing.

**Live site:** https://fariat14.github.io/

## What is here

- **Projects & Portfolio:** selected public projects, including a documented World Cup forecast and machine learning analysis of firm innovation in Bangladesh.
- **Skills & Work Experience:** tools and methods I use, plus a timeline of finance, analytics, research, and teaching roles.
- **Conferences, Publication & Speaking:** research presentations and invited talks.
- **Writing & Recognition:** published articles, leadership training, and selected awards.
- **Full record:** [`/record/`](https://fariat14.github.io/record/) includes additional awards, service, writing, and training.

The project repositories and dashboards linked from the portfolio are maintained separately. This repository contains the website itself.

## Site structure

- `index.html` — homepage, styles, and portfolio content
- `record/index.html` — full record
- `assets/` — website images and other static assets
- `sitemap.xml` and `robots.txt` — search indexing files

## Run locally

This is a static site with no build step or package dependencies. From the repository root, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`. GitHub Pages serves the site from the repository's default branch.
